# Owned gear, combat timing and Settings

This increment adds an account-owned item inventory, an OSRS equipment-tab layout, a third guide loadout selected from available owned equipment, and target-specific DPS/expected-kill timing. The guide remains independently navigable; owned gear and combat skills belong to the selected plan profile.

Character Export source was checked at `d790a93e24c9d946949f47645b0447210b166d93`. It exports bank, inventory and worn equipment as separate `kind`/`items` snapshots. Group Storage is not a supported exporter container. The planner accepts an explicitly identified Group Storage snapshot in the same data-only format, and manual group-item entry, with group availability off by default. No public bank lookup or game-account credentials are used.

The implementation uses the pinned OSRS Wiki DPS engine, with its source and GPL-3.0 licence included. Application code is distributed under GPL-3.0; Wiki data and game artwork retain separate attribution. No calculation logic is copied into a less complete home-grown formula. The adapter supplies actual equipment, attack styles, skills, potion/prayer assumptions and the selected NPC form. Expected hits-to-kill includes overkill; attack uptime, between-kill delay and task travel remain separate. Boss phases/switches are displayed as encounter DPS and retain configured full-fight timing in the hunter.

Owned-item selection is a deterministic bounded search, labelled best found rather than a proof of global optimality. It preserves necessary protection, two-handed constraints, ammunition compatibility and known skill requirements. Unknown equipment requirements require explicit acceptance. Bank quantities indicate availability, not charges, trip duration, quest unlocks or supply consumption. Snapshot replacement preserves manual absolute-quantity overrides; containers and group items remain distinct. Profiles and backups retain the inventory and combat assumptions.

Settings owns presentation preferences and optional combat assumptions. Open-area flags use an explicit reviewed allowlist; access means the ordinary entrance, not access to every locked wing or every creature. Quest/skill-gated locations remain conditional. Restricted-account mode exposes the original manual controls without deleting their stored values.

## Reproduction and provenance

`npm ci`, `npm run typecheck` and `npm test` rebuild the engine and UI from the pinned source with the lockfile. The Windows application and source use GPL-3.0; separate dataset/artwork attribution is in THIRD_PARTY_NOTICES.txt. The share includes the corresponding tracked source and build scripts in source/, with the exact Git revision in SOURCE-REVISION.txt.

The open-area allowlist has 20 ordinary entrances and 21 flags (two existing Stronghold Slayer Cave names). It means a normal members-world entrance without a quest/skill prerequisite, allowing money/tools and danger, not combat feasibility at level 3 or every gated wing. Four bounded explicit Wiki API requests captured the new sources, eight seconds apart. Normal builds and use never fetch them. Additional equipment art was built from the existing pinned DPS checkout; no Wiki artwork crawl was performed.

Equipment requirement extraction validates the OSRSBox input SHA-256; unknown records remain unknown. The RuneLite item-name dataset and both art atlases retain pinned source commits and hashes. See vendor/osrs-dps/PROVENANCE.md for the unchanged upstream source, build-only alias index optimization and browser flags.
