# Automatic quest points — 3.0.9

Quest points are used by `blockSlots` to determine ordinary Slayer block capacity: one slot per 50 points, capped at six, plus one for confirmed Lumbridge Elite. This feeds plan legality, automatic block searches, recommendations and KPH. Mortimer retains its separate two-slot rule. An explicit hypothetical block-limit override still takes precedence for other masters.

An empty **Quest points (manual override)** field now means automatic calculation. The UI shows the total or a confirmed minimum and explains missing reward records. An entered number remains an explicit override, with **Use quest-derived total** to clear it. Existing entered totals are preserved through upgrades and imports; new custom characters start automatic. New Maxed scenarios use the reward catalogue's maximum as their account-completion assumption, while existing Maxed totals are preserved.

Quest imports retain recognised reward states separately from the smaller access checklist, so ordinary completed quests such as Cook's Assistant count without cluttering area-access controls. Manual quest overrides win over imported states. Import previews use the same override policy as the eventual application. Character JSON preserves the reward snapshot; legacy filtered imports remain readable and show their incomplete coverage. Reimport quests.json to recover states discarded by older versions.

Ordinary completed quests award their captured reward; not-started/in-progress ordinary quests contribute zero. Recipe for Disaster uses completed subquests while unfinished, and its ten-point parent reward replaces the subquest sum after completion. It is never counted twice. Recognised miniquests award zero. Omitted records are unknown; unknown started/completed quests prevent claiming an exact total. Partial records grant only confirmed minimum block slots. Once at least 300 points are proven, missing rewards cannot increase ordinary QP capacity further. Diary uncertainty remains separate.

The offline catalogue is generated by `tools/build_quest_points.py` from one retained rendered Quests/List table and RuneLite's Quest names/enum aliases. The table contains 191 aggregate quests, ten Recipe for Disaster reward stages and nineteen zero-point miniquests; the captured rewards sum to 354 points after removing the aggregate/subquest duplication. The source revision identifies the outer list page; transcluded rewards reflect capture time, not that revision alone. Both capture and version are recorded. Runtime derivation makes no Wiki or account requests.

Source collection used bounded fixed API batches and one rendered table request, separated by other work; it did not crawl individual quest pages. RuneLite's retained Quest.java includes its copyright/licence. The share includes metadata, generator, source snapshots and notices.

## Verification

Passed: production build, strict TypeScript and all 303 JavaScript tests. New regressions cover ordinary rewards, exact zero/full totals, partial Recipe for Disaster, overrides, confirmed block thresholds, unknown quests/miniquests, old exports, invalid states, setup, cache identity and deterministic offline generation. The existing unknown-capacity fixture now explicitly records only its two required quests complete, rather than inheriting enough Maxed quest completions to prove block slots.

The selected character had Lumbridge Elite disabled. Native desktop interaction and live-game exports were not repeated.
